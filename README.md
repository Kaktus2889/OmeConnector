# OmeConnector

Projekt do łączenia obrazu i dźwięku z rozmowy Discord z wirtualną kamerą i mikrofonem dla OmeTV.

## Moduły

- extension/ — rozszerzenie Chromium z overlayem OmeTV, ustawieniami i pierwszym Auto Skip.
- desktop/ — planowany moduł przechwytywania obrazu Discorda, układu 2×2 i miksowania audio.

Instrukcja rozszerzenia znajduje się w extension/README.md.
